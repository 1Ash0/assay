## Strata look-test result

**Question:** Is the Strata context-composition view compelling enough to build in 3D for M3?

**Verdict: YES.** The look-test on session 4a153124 (E--surfacelab, 1325 turns, 9 compactions) revealed:

1. **Clear sawtooth pattern.** Cache read grows steadily between compactions, then drops sharply. The 9 compaction events are visually unmistakable. This story is invisible in the raw JSONL.

2. **Scale variation is dramatic.** Context ranges from ~53k tokens (post-compaction) to ~951k tokens (pre-compaction at T1298). That's an 18× range within a single session.

3. **Long stretches tell different stories.** T541→T879 (338 turns) grew from 85k to 443k before compaction — a long, deep session. T879→T1304 (425 turns) grew from 104k to 951k — the session's most intensive stretch. Short stretches show quick compactions.

4. **Tool call distribution is visible.** The tool activity strip shows dense tool use in the first ~540 turns (E--surfacelab is a coding project), sparser in the long second stretch.

5. **Composition is >99% cache read.** Output and cache write are thin slivers. This confirms the working hypothesis: for a long running session, nearly all context is reused prior context. New input and output per turn are small. The 3D "depth" axis should encode something other than this — perhaps time since first write, or recency decay.

**Artifact:** https://claude.ai/artifact/PqRT8R6AeHzewXCtzbT46E (private, M0 look-test)

**Implication for M3 design:** The 2D chart already tells the story cleanly. The 3D rendering is worth building because:
- Multiple sessions can be laid out in the Z dimension for comparison
- The "Strata" metaphor (geological layers over time) works best when you can see the cross-section
- Cache-write spikes (T880: compaction summary 94k, T1056: Artifact 14k, T1188: large output 17k) become navigation anchors
